# Hermes Desktop

Open-Source Desktop-App für Hermes Agent von Nous Research (184K+ GitHub Stars, MIT-lizenziert). Hermes ist ein selbst-lernender AI-Agent mit persistentem Memory, Tool-Nutzung und Multi-Plattform-Messaging. Die Desktop-App bietet denselben Agent wie die CLI – mit grafischer Oberfläche, Streaming-Output, Voice und Side-by-Side-Previews.

## Funktionen

- Streaming-Responses mit Live-Tool-Aktivität und Side-Panel für Vorschauen
- Persistentes Memory und selbst-lernende Skill-Dynamik
- Voice Input/Output und Drag-and-Drop für Dateien
- Multi-Profile und Bot-Mode für spezialisierte Agenten
- Plattformübergreifend: macOS, Windows, Linux

## Installation

Die mitgelieferten Skripte installieren Hermes Desktop:
- **Linux:** `Hermes-Desktop.bash`
- **Windows:** `Hermes-Desktop.ps1`
