# OpenCode Desktop

Open-Source AI Coding Agent als Desktop-App von Anomaly (195K+ GitHub Stars). OpenCode unterstützt 75+ LLM-Provider und bietet einen grafischen Ableiter des Terminal-TUI mit Session-Management, integriertem Editor und Multi-Window-Support. Die Desktop-App ist aktuell in Beta.

## Funktionen

- Grafische Oberfläche mit Drag-and-Drop, System-Tray und Keyboard Shortcuts
- Multi-Session-Management mit Verlauf und Lesezeichen
- Integrierter Code-Editor mit Syntax-Highlighting und Diff-Viewer
- Provider-agnostisch: Claude, GPT, Gemini, Mistral, lokale Modelle via Ollama u.v.m.
- Plattformübergreifend: macOS, Windows, Linux

## Installation

Die mitgelieferten Skripte installieren OpenCode Desktop:
- **Linux:** `OpenCode-Desktop.bash`
- **Windows:** `OpenCode-Desktop.ps1`
