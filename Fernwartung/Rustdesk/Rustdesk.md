# RustDesk

Open-Source-Fernwartungssoftware für sicheren Remote-Zugriff auf Computer und Geräte. RustDesk bietet eine selbst-hostbare Alternative zu proprietären Lösungen wie TeamViewer oder AnyDesk. Der Client und Server sind vollständig quelloffen, sodass Sie die volle Kontrolle über Ihre Daten behalten.

## Funktionen

- Fernsteuerung von Maus und Tastatur auf entfernten Computern
- Dateiübertragung zwischen verbundenen Geräten
- Ende-zu-Ende-Verschlüsselung für alle Verbindungen
- Self-Hosting-Option für maximale Kontrolle
- Plattformübergreifend: Windows, macOS, Linux, iOS, Android, Webbrowser

## Installation

Die mitgelieferten Skripte installieren RustDesk:
- **Linux:** `Rustdesk.bash`
- **Windows:** `Rustdesk.ps1`
