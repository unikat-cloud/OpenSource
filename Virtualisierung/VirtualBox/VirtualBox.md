# VirtualBox

Open-Source-Virtualisierungssoftware von Oracle für x86/AMD64. VirtualBox ermöglicht das Ausführen mehrerer Betriebssysteme gleichzeitig auf einem Rechner. Der Kern ist als GPLv2 lizenziert, die Extension Packs (USB 2.0+, RDP, Verschlüsselung) sind proprietär.

## Funktionen

- Vollständige Virtualisierung (Type-2-Hypervisor)
- Snapshots, Clones, Shared Folders
- USB 2.0/3.0, RDP, Verschlüsselung (via Extension Pack)
- OVF/OVA Import/Export
- Plattformübergreifend: Windows, macOS, Linux

## Installation

Die mitgelieferten Skripte installieren VirtualBox:
- **Linux:** `VirtualBox.bash`
- **Windows:** `VirtualBox.ps1`
