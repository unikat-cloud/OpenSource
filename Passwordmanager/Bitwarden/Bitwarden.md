# Bitwarden

Open-Source-Passwortmanager mit Ende-zu-Ende-Verschlüsselung und plattformübergreifender Synchronisierung. Bitwarden bietet sowohl einen kostenpflichtigen Cloud-Dienst als auch die Möglichkeit zur Selbsthostung über den eigenen Server. Sowohl die Clients als auch der Server sind als Open Source lizenziert.

## Funktionen

- Sichere Passwortspeicherung mit AES-256-Verschlüsselung
- Automatisches Ausfüllen von Login-Formularen
- Passwortgenerator für sichere Zugangsdaten
- Zwei-Faktor-Authentifizierung (TOTP)
- Plattformübergreifend: Windows, macOS, Linux, Android, iOS + Browser-Erweiterungen

## Installation

Die mitgelieferten Skripte installieren Bitwarden:
- **Linux:** `Bitwarden.bash`
- **Windows:** `Bitwarden.ps1`
