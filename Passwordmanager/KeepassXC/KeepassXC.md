# KeePassXC

Open-Source-Passwortmanager für den Desktop, der Passwörter lokal in einer verschlüsselten Datenbank speichert. KeePassXC ist ein Fork von KeePass und legt den Schwerpunkt auf Sicherheit und Offline-Nutzung. Es werden keine Daten in die Cloud übertragen – alle Zugangsdaten verbleiben auf Ihrem Gerät.

## Funktionen

- Lokale, verschlüsselte Passwortdatenbank (AES-256)
- Auto-Type-Funktion zum automatischen Eintippen von Passwörtern
- Browser-Integration für das Ausfüllen von Web-Formularen
- TOTP-Unterstützung für Zwei-Faktor-Authentifizierung
- Plattformübergreifend: Windows, macOS, Linux

## Installation

Die mitgelieferten Skripte installieren KeePassXC:
- **Linux:** `KeepassXC.bash`
- **Windows:** `KeepassXC.ps1`
