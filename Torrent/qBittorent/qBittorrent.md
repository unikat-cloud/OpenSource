# qBittorrent

Freier Open-Source-BitTorrent-Client ohne Werbung oder gebündelte Zusatzsoftware. qBittorrent ist eine leichtgewichtige, aber funktionsreiche Alternative zu anderen Torrent-Clients und legt Wert auf eine saubere Nutzererfahrung. Der Quellcode ist vollständig einsehbar und wird von einer Community Freiwilliger gepflegt.

## Funktionen

- Integrierte Torrent-Suchmaschine
- Web-Benutzeroberfläche für Fernverwaltung (ideal für Server)
- Sequenzielles Herunterladen für Media-Streaming
- Unterstützung für Magnet-Links, DHT, PeX, LSD und IPv6
- Plattformübergreifend: Windows, macOS, Linux, FreeBSD

## Installation

Die mitgelieferten Skripte installieren qBittorrent:
- **Linux:** `qBittorent.bash`
- **Windows:** `qBittorent.ps1`
