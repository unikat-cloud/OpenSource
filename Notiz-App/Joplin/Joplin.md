# Joplin

Freie Open-Source-Notiz-App mit Ende-zu-Ende-Verschlüsselung und Markdown-Unterstützung. Joplin ist eine Alternative zu proprietären Notiz-Apps wie Evernote und ermöglicht die Synchronisierung über verschiedene Cloud-Dienste. Der Quellcode ist auf GitHub einsehbar und die App kann selbst gehostet werden.

## Funktionen

- Markdown-basierte Notizen mit Rich-Text-Editor
- Ende-zu-Ende-Verschlüsselung für sensible Notizen
- Synchronisierung über Nextcloud, WebDAV, Joplin Cloud u.a.
- Notizbücher, Tags und verschachtelte Ordner
- Plattformübergreifend: Windows, macOS, Linux, Android, iOS

## Installation

Die mitgelieferten Skripte installieren Joplin:
- **Linux:** `Joplin.bash`
- **Windows:** `Joplin.ps1`
