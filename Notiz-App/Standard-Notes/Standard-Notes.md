# Standard Notes

Freier Open-Source-Notiz-Editor mit Fokus auf Sicherheit und Ende-zu-Ende-Verschlüsselung. Standard Notes wurde 2024 von Proton übernommen, bleibt aber Open Source und konzentriert sich weiterhin auf Datenschutz. Die App ist einfach gehalten und auf Langlebigkeit ausgelegt.

## Funktionen

- Ende-zu-Ende-Verschlüsselung aller Notizen
- Einfacher, ablenkungsfreier Editor (Plain Text, erweiterbar)
- Plattformübergreifende Synchronisierung
- Tags und verschachtelte Ordner zur Organisation
- Plattformübergreifend: Web, Windows, macOS, Linux, Android, iOS

## Installation

Die mitgelieferten Skripte installieren Standard Notes:
- **Linux:** `Standard-Notes.bash`
- **Windows:** `Standard-Notes.ps1`
