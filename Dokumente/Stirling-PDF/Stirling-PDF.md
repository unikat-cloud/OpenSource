# Stirling PDF

Self-Hostable Open-Source-PDF-Toolbox als Desktop-App oder Web-Dienst. Stirling PDF bietet Funktionen zum Zusammenführen, Trennen, Konvertieren, Signieren und OCR von PDF-Dateien – alles lokal ohne Cloud-Upload. Als Desktop-App für Windows und Linux verfügbar.

## Funktionen

- PDFs zusammenführen, trennen, rotieren, komprimieren
- PDF-Konvertierung (Word, Bild, HTML u.v.m.)
- OCR für gescannte Dokumente
- PDFs signieren und annotieren
- Plattformübergreifend: Windows, Linux (macOS via Java)

## Installation

Die mitgelieferten Skripte installieren Stirling PDF:
- **Linux:** `Stirling-PDF.bash`
- **Windows:** `Stirling-PDF.ps1`
