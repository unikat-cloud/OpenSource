# VSCodium

Open-Source-Build von Visual Studio Code ohne Microsoft-Branding und Telemetrie. VSCodium bietet dieselbe leistungsstarke IDE wie VS Code, ist aber vollständig unter MIT lizenziert und sammelt keine Nutzungsdaten. Unterstützt alle VS Code-Erweiterungen.

## Funktionen

- Leistungsstarke IDE mit IntelliSense, Debugging und Git-Integration
- Keine Telemetrie und kein Microsoft-Account erforderlich
- Kompatibel mit VS Code-Erweiterungen
- Integrierter Terminal und Code-Runner
- Plattformübergreifend: Windows, macOS, Linux

## Installation

Die mitgelieferten Skripte installieren VSCodium:
- **Linux:** `VSCodium.bash`
- **Windows:** `VSCodium.ps1`
