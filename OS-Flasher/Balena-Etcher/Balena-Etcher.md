# Balena Etcher

Kostenloses Open-Source-Tool zum Flashen von Betriebssystem-Images auf SD-Karten und USB-Laufwerke. Etcher zeichnet sich durch eine extrem einfache Bedienung aus und verhindert versehentliches Überschreiben von Festplatten. Das Tool validiert automatisch das geflashte Medium, um Fehler auszuschließen.

## Funktionen

- Flashen von .iso, .img, .zip und anderen Image-Formaten
- Automatische Validierung des geflasheden Mediums
- Schutz vor dem versehentlichen Überschreiben von Festplatten
- Einfache Dreiklick-Bedienung
- Plattformübergreifend: Windows, macOS, Linux

## Installation

Die mitgelieferten Skripte installieren Balena Etcher:
- **Linux:** `Balena-Etcher.bash`
- **Windows:** `Balena-Etcher.ps1`
