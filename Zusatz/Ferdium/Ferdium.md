# Ferdium

Open-Source-Desktop-App zum zentralen Verwalten mehrerer Messaging-Dienste in einer einzigen Anwendung. Ferdium ist ein Fork von Franz und unterstützt Dienste wie WhatsApp, Telegram, Slack, Discord und viele mehr. Der Quellcode ist vollständig einsehbar und wird von einer Community weiterentwickelt.

## Funktionen

- Zentrale Verwaltung vieler Messaging-Dienste in einer App
- Workspaces zur Trennung von privat und beruflich
- Individuelle Benachrichtigungseinstellungen pro Dienst
- Dunkler Modus und anpassbare Oberfläche
- Plattformübergreifend: Windows, macOS, Linux

## Installation

Die mitgelieferten Skripte installieren Ferdium:
- **Linux:** `Ferdium.bash`
- **Windows:** `Ferdium.ps1`
