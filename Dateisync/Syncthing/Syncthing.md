# Syncthing

Open-Source-Dateisynchronisation Peer-to-Peer ohne zentralen Server. Syncthing synchronisiert Dateien zwischen mehreren Geräten in Echtzeit, verschlüsselt und ohne Cloud-Abhängigkeit. Ihre Daten bleiben auf Ihren Geräten.

## Funktionen

- Peer-to-Peer-Synchronisation ohne zentralen Server
- Ende-zu-Ende-Verschlüsselung aller Daten
- Echtzeit-Synchronisation zwischen Geräten
- Versionierung und Konfliktbehandlung
- Plattformübergreifend: Windows, macOS, Linux, Android

## Installation

Die mitgelieferten Skripte installieren Syncthing:
- **Linux:** `Syncthing.bash`
- **Windows:** `Syncthing.ps1`
